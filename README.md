# 🚀 GDG UNIKA - Web Projects

Repositori ini berisi proyek-proyek web sederhana yang dikembangkan dalam rangkaian acara **Google Developer Groups (GDG) on Campus UNIKA Soegijapranata Semarang**.

Semua proyek dibangun menggunakan pure HTML, JavaScript vanilla, dan styling modern dari **Tailwind CSS**.

---

## 📂 Daftar Proyek

| Proyek | Deskripsi | Tech Stack |
| :--- | :--- | :--- |
| **🤖 Burger Blenger Chatbot** (`chatbot`) | Prototipe UI Chatbot interaktif untuk pemesanan & FAQ kuliner burger/kebab dengan sistem Knowledge-Base berbasis JavaScript. | HTML5, Tailwind CSS, JavaScript |
| **🍰 Dani Bakery Landing Page** (`landingpage`) | Landing page berestetika premium bertema cokelat dengan tipografi elegan, value proposition, dan responsif. | HTML5, Tailwind CSS, Google Fonts |

---

## 🛠️ Fitur Utama

### 1. Chatbot Burger Blenger (`chatbot`)
- **Knowledge-Base Response:** Mampu menjawab otomatis pertanyaan umum seputar lokasi, jam buka, menu, harga, pemesanan, pengiriman, dan promo.
- **Modern Chat Bubble UI:** Desain obrolan yang clean dan responsif dengan Tailwind CSS.
- **Interactive UI:** Mengirim pesan melalui tombol *Kirim* maupun enter key.

### 2. Dani Bakery Landing Page (`landingpage`)
- **Hero Section:** Dilengkapi headline persuasif, call-to-action (CTA) button, dan background overlay.
- **Value Proposition Grid:** Menampilkan keunggulan produk (organik, resep otentik, kualitas premium).
- **Luxury Color Palette:** Perpaduan warna *Dark Chocolate*, *Gold*, dan *Cream* serta Google Font *Playfair Display* & *Inter*.
- **Responsive Navigation:** Navbar sticky yang siap digunakan di berbagai ukuran layar.

## 💻 Cara Menjalankan

Karena proyek ini berbasis front-end murni (client-side), Anda tidak membutuhkan web server atau instalasi dependencies yang rumit:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Luthfi1006/GDG-UNIKA.git
   cd GDG-UNIKA
   ```

2. **Jalankan langsung di browser:**
   - Buka file `chatbot` atau `landingpage` langsung dengan double-click, atau rename menjadi `.html` (misal: `chatbot.html` dan `landingpage.html`).
   - Atau melalui terminal (PowerShell):
     ```powershell
     Start-Process chatbot.html
     ```
